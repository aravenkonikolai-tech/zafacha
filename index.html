Настройки Telegram бота

Инструкция по созданию бота:

  1. Откройте Telegram и найдите @BotFather
  2. Отправьте команду /newbot
  3. Придумайте имя бота (например: My Kanban Notifier)
  4. Придумайте username бота (должен заканчиваться на bot, например: my_kanban_notifier_bot)
  5. Скопируйте токен, который вам выдаст BotFather (выглядит примерно так: 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz)
  6. Найдите созданного бота в Telegram и отправьте ему команду /start
  7. Скопируйте ваш Chat ID (нажмите кнопку "Получить Chat ID" ниже)
  8. Вставьте токен и Chat ID в поля ниже
